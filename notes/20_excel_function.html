Lookup Functions
3 Formulas
#14
VLOOKUP
Lookup
=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
Vertically (column mein) kisi value ko table mein dhundta hai aur corresponding value return karta hai.
#15
HLOOKUP
Lookup
=HLOOKUP(lookup_value, table_area, row_index_num, [range_lookup])
Horizontally (row mein) kisi value ko table mein dhundta hai aur corresponding value return karta hai.
#16
INDEX-MATCH
Lookup
=INDEX(area, row_number, [col_number])
INDEX aur MATCH ka combination — VLOOKUP se zyada powerful. Kisi bhi direction mein value dhundh sakta hai. MATCH row/column number dhundta hai, INDEX value return karta hai.
💡
Pro Tip: VLOOKUP sirf left-se-right kaam karta hai. Agar reverse dhundhna ho toh INDEX-MATCH use karein — ye zyada flexible hai!

Financial Functions
3 Formulas
#20
PMT
Finance
=-PMT(Rate/12, Time_period*12, Loan_amount)
Per Month Instalment calculate karta hai. Loan lene par har mahine kitna dena hoga. Negative sign isliye kyunki ye cash outflow hai.
#21
IPMT
Finance
=-IPMT(Rate/12, Installment_no, Time*12, Loan_amount)
Interest Payment — Kisi specific installment mein kitna sirf interest pay kiya ja raha hai.
#22
PPMT
Finance
=-PPMT(Rate/12, Total_installments, Time*12, Loan_amount)
Principal Payment — Kisi installment mein kitna actual loan amount wapas ho raha hai.
💡
Yaad rakhein: PMT = IPMT + PPMT. Matlab har installment mein kuch hissa interest ka hota hai aur kuch principal ka. Shuruat mein interest zyada hota hai, baad mein principal.
